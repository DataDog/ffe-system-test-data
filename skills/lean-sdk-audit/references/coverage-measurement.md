# Measure the change in verification

Keep a machine-readable matrix with one row per behavior and implementation owner. Each cell records status, exact native assertion or absence-search scope, a shared scenario/proof ID, source SHA, and evidence path. Useful status values are existing, newly-detected, redundant, contract-gap, excluded and unknown. An absent assertion found by reading is a candidate gap, not measured defect sensitivity.

For a paired experiment, lock actual production source plus its existing test suite. Run the clean source through baseline and new adapter first. Introduce one realistic mutation in an isolated copy; both arms see the identical mutation. Record baseline and new pass/fail, compile failures, environment failures and exclusions. Repair or clean controls must pass. Count only valid mutations: incremental detection is newly killed mutations / baseline survivors among valid mutations. Keep the denominator, defect families and untested domains visible. No mutation survivor is proof that a test suite is bad; first verify reachability and that the mutation changes required behavior.

For consolidation, count existing semantic-only test blocks and nonblank source lines with reproducible ranges. Separate schema, parser, serialization, locking, scheduler, transport, queue, lifecycle and platform tests. Proposed net maintenance change is removed semantic test LOC minus added shared contract/proof/generator LOC minus native adapter LOC minus newly required local regression LOC. Report both before and after. Generated case data is a separate byte/case count. A central model that adds more authored code than it replaces may still improve coverage, but is not a LOC reduction.

Do not delete native tests until the replacement exercises the same production path, the paired experiment preserves their sensitivity, and retained integration assertions are identified. Initially run both arms. Deleting a duplicate semantic assertion is different from deleting a test whose fixture, synchronization or serialization assertions still matter.
